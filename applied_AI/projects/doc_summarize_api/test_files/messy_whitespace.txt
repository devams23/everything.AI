Agenda Items Discussed

1. Project Scope

The team agreed on a phased delivery approach. Phase 1 targets a working MVP
by end of Q2. Phase 2 adds analytics and reporting features in Q3.


2. Tech Stack Decision

After discussion, the team chose React for the frontend and FastAPI for the
backend. The database will be PostgreSQL. All services will be containerised
with Docker and deployed on AWS.
