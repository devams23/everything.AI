# Phase 3 — Problem → Agent (the core skill)

**Goal:** given a vague business problem, produce a clear, defensible agentic solution design *before* writing any code.

- [`framework.md`](framework.md): the step-by-step method.
- [`templates/solution_design.md`](templates/solution_design.md): a fill-in-the-blanks design doc.
- [`case_studies/`](case_studies/): one file per practice problem (`NN_short_name.md`). `00_worked_example.md` shows the method end to end.

## Exit criteria
- [ ] I've done at least 6 case studies across different domains.
- [ ] At least 2 of them concluded "don't use an agent here", and I could justify it.
- [ ] Each case study has success metrics and an eval plan, not just an architecture diagram.
